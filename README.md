# ROB RUN Auto Fire Module

Download: soon

Auto fire when the crosshair covers a target, with delay, zone and pulse control.

| Setting | Default | Range |
| --- | --- | --- |
| delay | 40 ms | 15-120 |
| zone | 3 px | 2-9 |
| pulse | 8 ms | 4-20 |
| visible | on | on/off |
| hotkey | F8 | any |

## Notes on delay

The city mixes thin cover with tight angles, so visible-only stays on. 40 ms is readable, 25 ms obvious, 60 ms safe on high ping.

## Install

Admin loader, game, INSERT for values, F8 toggles.

## Troubleshooting

Double taps: pulse shorter. No fire: zone up. Through cover: visible off.

Windows 10/11, Steam, EAC.
